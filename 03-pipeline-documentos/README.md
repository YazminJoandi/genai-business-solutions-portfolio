# Pipeline de documentos para generación de matriz de pruebas

## Objetivo
Automatizar la generación de escenarios de prueba a partir de documentos funcionales.

## Problema de negocio
El diseño manual de casos de prueba consume tiempo y puede omitir escenarios importantes. Esta solución ayuda a generar una primera versión estructurada de la matriz.

## Entrada
Documentos funcionales en PDF o Word.

## Salida
Archivo Excel con columnas:
- Escenario
- Precondición
- Objetivo
- Validaciones
- Datos de validación
- Resultado esperado

## Herramientas usadas
- OneDrive / SharePoint
- Power Automate
- Copilot Studio / LLM
- Excel
- JSON estructurado

## Valor de negocio
Reduce el tiempo inicial de diseño de pruebas y estandariza la documentación.
