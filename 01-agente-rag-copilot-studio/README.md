# Agente RAG con Copilot Studio

## Objetivo
Construir un agente conversacional capaz de responder preguntas usando documentos internos como fuente de conocimiento.

## Problema de negocio
Los usuarios pierden tiempo buscando información en documentos dispersos. El agente permite consultar la información desde una conversación natural.

## Herramientas usadas
- Microsoft Copilot Studio
- SharePoint / OneDrive
- Power Automate
- Microsoft 365

## Flujo general
1. El usuario hace una pregunta.
2. El agente consulta la fuente de conocimiento.
3. El agente responde con base en la información disponible.
4. Si no encuentra información suficiente, indica que no tiene contexto suficiente.

## Buenas prácticas aplicadas
- Respuestas basadas en documentos.
- Instrucciones para evitar inventar información.
- Tono profesional.
- Escalamiento cuando no hay información suficiente.
